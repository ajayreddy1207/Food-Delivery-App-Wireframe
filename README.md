# 🍔 Food Delivery App Wireframe

## UI/UX Internship – Task 1

A low-fidelity wireframe project for a **Food Delivery Mobile Application**, designed as part of a UI/UX internship task. The project focuses on understanding the fundamentals of **user research, user personas, user flows, wireframing, and the design thinking process**.

The wireframes were created using **Figma** with a focus on creating a simple and user-friendly food ordering experience.

---

## 🎯 Objective

The main objective of this project is to understand and apply the basic stages of the UI/UX design process:

* User Research
* User Persona Creation
* User Flow Design
* Low-Fidelity Wireframing
* Design Thinking
* Mobile App User Experience

---

Improved User Experience
