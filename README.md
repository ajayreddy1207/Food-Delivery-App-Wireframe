# 🍔 Food Delivery App Wireframe

## UI/UX Internship – Task 1

A **low-fidelity wireframe project for a Food Delivery Mobile Application**, created as part of a UI/UX internship task.

The project focuses on understanding the fundamentals of the **UI/UX design process**, including user research, user persona creation, user flow, wireframing, and design thinking.

The wireframes were designed using **Figma**, with the goal of creating a simple, intuitive, and user-friendly food ordering experience.

---

## 🎯 Project Objective

The main objective of this project is to understand and apply the fundamental stages of the UI/UX design process.

### Key Objectives

* Understand user requirements
* Identify the target users
* Create a user persona
* Design a clear user flow
* Create low-fidelity wireframes
* Apply design thinking principles
* Improve the overall mobile user experience

---

## 📱 Screens & Design Components

The project consists of **7 major UX design artifacts and wireframe screens**.

---

### 1. 🔐 Login Screen

The login screen provides users with a simple and straightforward way to access the food delivery application.

It focuses on keeping the authentication experience simple and easy to understand.

![Login Screen](./iPhone%2017%20-%201%20%281%29.png)

---

### 2. 🏠 Home Screen

The home screen acts as the primary entry point of the application.

It allows users to explore available food options and navigate through the application easily.

![Home Screen](./iPhone%2017%20-%202%20%281%29.png)

---

### 3. 🍕 Food Details Screen

The food details screen provides users with information about a selected food item.

Users can review the food details before deciding to add the item to their cart.

![Food Details Screen](./iPhone%2017%20-%203%20%281%29.png)

---

### 4. 🛒 Cart Screen

The cart screen allows users to review the food items they have selected.

It provides a clear overview of the selected items before proceeding with the ordering process.

![Cart Screen](./iPhone%2017%20-%204%20%281%29.png)

---

### 5. 👤 User Persona

A user persona was created to understand the target user's:

* Goals
* Needs
* Behaviors
* Pain points
* Expectations

Creating a persona helped in designing the application around the user's requirements.

![User Persona](./iPhone%2017%20-%205%20%281%29.png)

---

### 6. 🔄 User Flow

The user flow represents the journey a user follows while interacting with the food delivery application.

It helps understand how users move from one stage of the application to another.

### Basic User Journey

```text
Open Application
       ↓
     Login
       ↓
   Home Screen
       ↓
 Select Food
       ↓
 Food Details
       ↓
  Add to Cart
       ↓
   View Cart
       ↓
   Place Order
```

![User Flow](./iPhone%2017%20-%206%20%281%29.png)

## 🎨 Design Goals

The main design goals of the application are:

### Simplicity

Keep the interface simple so users can easily understand and navigate the application.

### Usability

Make important actions such as selecting food and viewing the cart easy to access.

### User-Centered Design

Design the application based on user needs, expectations, and pain points.

### Consistency

Maintain a consistent structure and navigation pattern throughout the application.
